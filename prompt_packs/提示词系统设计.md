# 粉底液详情页提示词系统 V3

## 一、结论先行

这次不是继续“想更好看的词”，而是把提示词改成一套可计算的生产规格。

**第一性原则：图片不是先追求“高级”，而是先保证每个可见元素都能回答一个购买问题。**

链路必须是：

`商品事实 → 买家问题 → 页面任务 → 视觉证据 → 镜头/材质/光线 → 文案层级 → 生成参数 → 质检`

任何不能落到这 8 个节点的形容词，都不应进入最终 Prompt。

---

## 二、为什么之前不够好

| 问题 | 后果 |
|---|---|
| 把“统一”写成同一背景、同一石材台、同一左文右图 | 12 张像换文案的克隆图 |
| Prompt 只有“高端、精致、柔光”等抽象词 | 模型只能自由发挥，结果不可控 |
| 没写产品占比、留白、文案安全区 | 文字压到商品、画面过满或空洞 |
| 没写镜头、焦段、景别 | 全套默认 3/4 正面，缺乏节奏 |
| 文字任务和图像任务混在一起 | 模型同时猜版式和文案，容易错字、漏字 |
| 用 Midjourney 的 `--ar`、`--v` 等尾缀 | Seedream 不按这些参数工作，长尾关键词反而稀释主约束 |
| 每页没有明确的买家问题 | 图片只是“好看”，没有推进决策 |

## 三、可复用的输入区

左侧输入区只收集会改变画面的变量，默认值由系统补齐。

| 输入 | 作用 | 示例 |
|---|---|---|
| 产品名称/品类 | 决定页面模板与视觉证据 | ESTÉE LAUDER Double Wear 粉底液 |
| 平台与流量场景 | 决定比例、信息密度、CTA | 天猫/淘宝详情页，手机端竖屏 |
| 目标人群 | 决定生活场景和语言 | 通勤女性、底妆新手、送礼人群 |
| 转化驱动力 | 决定页面顺序 | 视觉/质感驱动 + 轻微痛点驱动 |
| Top 3 卖点 | 只保留三个购买理由 | 柔焦质地、轻盈贴合、持妆场景 |
| 证据 | 区分已确认与待补证 | 30ml、SPF 10/PA+++ 来自包装 |
| 风格与色板 | 锁定整套视觉 | 暖象牙、深海军蓝、古金 |
| 参考图 | 锁定商品身份 | 真实瓶身与包装照片 |
| 页面数量/比例 | 控制生产数量 | 12 页，4:5，2K |
| 文字策略 | 控制错字风险 | 短标题直出，长文案后期排版 |

## 四、右侧输出区：每一页必须有 12 个字段

1. `page_id`：页码与文件名。
2. `page_role`：首屏/质地/用法/规格等页面角色。
3. `buyer_question`：这一页只回答一个主要问题。
4. `decision_goal`：看完这一页，用户应相信或理解什么。
5. `product_position`：角度、位置、占比、是否裁切。
6. `scene`：背景材质、道具、空间关系。
7. `composition`：构图、景别、留白区、阅读顺序。
8. `camera`：焦段、机位、光圈、景深。
9. `lighting`：方向、软硬、色温、阴影。
10. `materials`：玻璃/金属/纸盒/布料/膏体等真实材质。
11. `copy_layer`：主标题、副标题、短标签、后期正文。
12. `qa_constraints`：具体禁止项和验图标准。

这 12 个字段合起来，才是一条“详细但可控”的提示词。

---

## 五、单页 Prompt 的固定公式

```text
[REFERENCE ROLE]
Image 1 = 真实商品照片，锁定瓶身、Logo、包装、标签与规格。

[CAMPAIGN LOCK]
整套图共享的色板、色温、字体、光线、材质语言和产品呈现规则。

[PAGE CONTRACT]
第 X 页｜页面角色｜买家问题｜决策目标。

[VISUAL]
画幅比例 + 产品位置与占比 + 场景 + 构图 + 机位/焦段 + 光影 + 材质。

[COPY]
主标题 + 副标题 + 短标签 + 文案安全区 + 文字策略。

[CONSTRAINTS]
产品不变形、不新增 SKU、不虚构认证、不错字、不水印、不杂乱。

[QA]
产品身份、文字、留白、色温、背景、角度、素材清晰度。
```

### 为什么不用堆 `8k`、`masterpiece`、`--ar`

这些词对 Seedream 的版式控制很弱，甚至会挤掉更重要的商品和留白信息。比例应使用接口参数；画质用镜头、光线、材质和清晰度约束表达；风格用色板、光线和构图表达。

## 六、12 页的组成方式

粉底液属于“视觉/质感驱动 + 轻度痛点”品类。默认 12 页结构：

| 页码 | 页面任务 | 买家问题 | 视觉主角 |
|---|---|---|---|
| 01 | 首屏氛围 | 这是什么，为什么值得看？ | 深蓝 Hero |
| 02 | 产品身份 | 包装和规格是否可信？ | 瓶身+外盒 |
| 03 | 质地证明 | 会不会厚重？ | 粉底膏体微距 |
| 04 | 轻薄触感 | 上脸是否闷、假面？ | 透明材质关系 |
| 05 | 柔焦妆效 | 柔焦是否看得见？ | 磨砂/透明表面对比 |
| 06 | 时间场景 | 一天使用是什么感觉？ | 双联画 |
| 07 | 使用步骤 | 第一次怎么用？ | 三步俯拍 |
| 08 | 工艺细节 | 为什么有质感？ | 瓶盖/纸盒微距 |
| 09 | 通勤场景 | 适合我的日常吗？ | 手袋/梳妆台 |
| 10 | 规格信息 | 容量与防晒信息？ | 目录式规格 |
| 11 | 适用场景 | 哪些时刻适合？ | 三列场景板 |
| 12 | 收束 | 看完记住什么？ | 品牌收束画面 |

**统一项**：色板、色温、字体气质、材质语言、产品身份、网格与安全边距。

**变化项**：页面任务、镜头、景别、背景材质、产品占比、文案位置、短文案。

## 七、文字策略

### 直接生成

- 主标题：4–8 个汉字。
- 副标题：6–12 个汉字。
- 短标签：1–4 个汉字或数字。
- 用「」包裹中文，降低错字概率。

### 后期排版

- 规格说明、步骤解释、长卖点、合规注释。
- 全部由设计层排版，避免 5.0 Lite 生成小字时出现错字和乱码。

原因：5.0 Lite 的成本更低，但长中文的准确率也更容易波动。把图像和文字分成两层，最终效果会更像真实美工交付，而不是让模型同时猜版式和文案。

---

## 八、模型与参数

- 目标模型：`Seedream 5.0 Lite`。
- 比例：`4:5` 竖屏，2K。
- 商品参考：真实实拍图，必须作为第一张参考图。
- 不使用 Pro。
- 不使用 `--ar`、`--v` 等 Midjourney 参数。
- 当前项目可读模型目录里没有 Lite 条目，已有 `5.0 Flash / 5.0 / 4.5 / 4.0`。生成前需补齐 Lite 的准确模型 ID，避免误用 Pro。

---

## 九、质检门

每页生成后按顺序检查：

1. **商品身份**：瓶身、瓶盖、Logo、包装结构和 SPF 标识是否一致。
2. **页面任务**：这一页是否只回答一个买家问题。
3. **版式**：标题、正文和产品是否互不遮挡，留白是否达到设定。
4. **镜头**：是否与前后页形成不同景别和角度。
5. **色调**：是否仍在同一组 hex 色板和 5000K 色温内。
6. **文字**：放大 200% 逐字核对，复杂字是否简化。
7. **合规**：是否出现无证据的认证、时长、效果或对比。
8. **生产可用**：是否能单独输出一页，不依赖整张长图裁切。

任一项失败，只重做当前页，不整套推翻。

## 十、复用其他品类的方法

不是把“粉底液”替换成“净水器”就结束，而是替换以下三类元素：

- **证据对象**：粉底液→膏体/瓶身；净水器→滤芯/水路/出水口。
- **核心镜头**：粉底液→质地微距；净水器→过滤结构剖切/出水动态。
- **买家问题**：粉底液→厚重/假面；净水器→滤芯更换/安装/水质。

页面角色库（首屏、证据、机制、利益、场景、用法、规格、对比、收束）保持不变，因此其他品类可以直接复用同一套提示词引擎。
