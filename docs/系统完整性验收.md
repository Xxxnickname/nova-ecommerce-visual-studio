# NOVA 系统完整性验收

版本：3.2.0  
验收日期：2026-10-25  
运行地址：http://127.0.0.1:8000

## 1. 验收目标

确认系统不是“能生成一张图”的演示，而是能从员工配置、商品识别、参考图上传、提示词审阅、单图/套图生成、商品草稿、资料补全、平台上架到任务留痕完整走通。

## 2. 已完成能力

### 本机配置与部署

- 页面填写 Seedream / Ark、DeepSeek、Shopify、飞书配置。
- 密钥仅保存在本机 `03-代码\settings.json`，不上传、不写日志。
- `setup.ps1` 创建独立 Python 环境；`启动电商中台.vbs` 启动本地服务。
- 设置页新增“系统自检”：数据库、图片目录、配置文件、API 配置、模板、风格图库、模型与平台目录。

### 生图工坊

- AI 识别商品类型或手动选择类型，二选一。
- 商品信息、参考实拍图、模型、分辨率、平台、尺寸、模板、场景、风格。
- 必填/选填在标题旁标注；补充项全部选填。
- 8 套原创风格参考；无品牌、无人物、无文字。
- 单图与 12 张套图；12 张提示词均可查看和编辑。
- 5 张信息图改为“Seedream 无文字背景 + 系统安全边距排版”，文字不会依赖模型随意摆放。
- 套图风格锁会跟随所选风格母版，不再固定使用同一套颜色。
- 品牌/系列名为选填；未填写时提示词明确禁止虚构品牌。
- 生成结果进入暂存区；套图叠放为一张卡片；双击打开居中大图查看器，支持左右翻页和关闭。
- 失败任务保留原参数，可在任务中心重试。

### 商品与发布

- 生成图或整套图可转为商品草稿。
- 旧生成图也保留品类信息；即使刷新页面或重新打开系统，也能继续转草稿。
- 商品资料支持 SKU、名称、类目、售价、成本、库存、重量、Packed size、标签、描述、平台。
- Shopify 为真实发布；淘宝/天猫为模拟发布；其他平台明确标注筹备中。
- 商品与任务操作留痕；改价任务可从任务中心回滚。

### 稳定性

- 服务重启时，遗留的排队/执行中任务会被标记为“失败/中断”，不会永久卡住。
- 失败生图任务可重试。
- 错误信息经过友好化处理，不把大段外部请求 ID 堆到页面上。
- 当前自动化测试：25 项通过。

## 3. 验收方式

1. 双击 `启动电商中台.vbs`。
2. 打开 http://127.0.0.1:8000 。
3. 进入“设置”填写本机 API Key。
4. 点击“运行完整性检查”。
5. 进入“生图工坊”，上传一张产品实拍图，先做单图测试。
6. 单图确认后，再生成 12 张套图。
7. 满意后点击“保存整套为商品草稿”。
8. 在“商品”补全价格、库存、Packed size，并发布 Shopify。
9. 在“任务”查看生图、发布、失败与回滚记录。

## 4. 当前边界

- 信息图文字已由系统排版，不再依赖 Seedream 直接写中文；商品包装上的原始小字仍可能失真，需要人工审阅。
- 淘宝/天猫只做模拟发布，不伪造真实平台调用。
- Amazon、TikTok Shop、京东、拼多多仅保留平台位。
- 当前为本地单机版，不做账号体系、多租户和云端任务队列。
