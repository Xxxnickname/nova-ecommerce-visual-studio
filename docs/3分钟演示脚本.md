# 3 分钟演示脚本

## 1. 定位（20 秒）

“这不是一个只负责出图的工具。它解决的是图片生成之后，如何绑定 SKU、同步商品资料、走审批和回滚的问题。”

## 2. 总览（20 秒）

展示商品数、Shopify 在售数、待审批、生成图数量。说明所有动作都有任务和日志。

## 3. 生图（70 秒）

1. 进入生图工坊，输入商品信息或直接选择商品类型。
2. 展示 AI 识别或手选后，模板、场景、风格自动切换。
3. 上传产品实拍图。
4. 填写卖点、必须保留、场景道具、禁止内容。
5. 点击生成提示词，展示 9 层结构与补充要求。
6. 点击生成商品图，等待结果。
7. 点击“保存为商品草稿”，系统跳转到商品中心。
8. 补全售价、库存、SKU 等资料，点击“一键上架”。

讲解点：实拍图只作为商品外观依据；生成图先成为待确认草稿，员工补全资料后才进入 Shopify。

## 4. 改价与审批（45 秒）

1. 在商品详情输入一个超过 5% 的价格。
2. 展示待审批。
3. 点击通过，再展示价格历史与回滚。
4. 说明低于成本价的改价会被直接拦截。

## 5. Agent（25 秒）

输入：“查一下 SKU-001 的库存，然后把 SKU-003 改到 130 元。”

说明：Agent 只能通过受控工具调用后台 API，不能直接改数据库，也不能绕过审批。

## 6. 收尾（20 秒）

“我使用的是成熟生成模型，不重复造模型。我的差异化在集成层：商品数据、上架、审批、回滚、通知和可观测性。”
