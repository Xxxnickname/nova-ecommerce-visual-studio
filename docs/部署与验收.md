# 部署与验收

## A. 当前电脑

1. 在 `03-代码` 中运行测试：`.\.venv\Scripts\python.exe -m pytest -q`。
2. 双击根目录 `启动电商中台.vbs`。
3. 打开设置页，确认 Seedream、DeepSeek、Shopify 显示“已配置”。
4. 分别点击 DeepSeek 与 Shopify 的“测试连接”。

## B. 新电脑

1. 复制整个 `电商自动化中台` 文件夹。
2. 若没有 `03-代码\.venv`，双击运行根目录 `setup.ps1`。
3. 双击 `启动电商中台.vbs`。
4. 在页面填写该员工自己的 API Key 和 Shopify Token。
5. 不复制其他员工的 `settings.json`。

## C. 验收清单

- [ ] 12 个 SKU 可以在商品中心看到
- [ ] 选 SKU 后能看到参考图
- [ ] DeepSeek 能生成 9 层提示词
- [ ] Seedream 能生成图片并保存到 `05-运行记录\生成图\SKU`
- [ ] 生成图可以设为商品主图
- [ ] 生成图可以同步到 Shopify 商品媒体
- [ ] 改价低于成本价会被拦截
- [ ] 超过 5% 的改价会进入审批
- [ ] 审批通过后价格生效，驳回后价格不变
- [ ] 成功改价可以回滚
- [ ] 任务与日志可以追溯
- [ ] 飞书未配置时不影响主流程，配置后可发通知
- [ ] Agent 可以查询 SKU、改价或上架

## D. 故障排查

| 现象 | 检查 |
|---|---|
| 页面打不开 | 端口 8000 是否被占用；运行 `停止电商中台.ps1` 后重启 |
| DeepSeek 失败 | Key、Base URL、模型名、网络代理 |
| Seedream 失败 | Ark Key、图像模型名、图片引用是否有效、账户额度 |
| Shopify 失败 | 店铺域名、Admin API Token、应用权限 |
| 生成的图不显示 | 查看 `05-运行记录\生成图` 是否存在对应文件 |
| 员工换了电脑 | 重新填写 Key；不要复用旧机器的 settings.json |
