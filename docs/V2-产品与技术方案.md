# V2 产品与技术方案

## 1. 要达成的结果

把 AI 生成结果变成可管理的商品资产，而不是停留在下载图片：

`SKU → 提示词 → 商品图 → 主图绑定 → Shopify 同步 → 审批/回滚 → 日志与通知`

## 2. 产品边界

### 做

- 商品资料与 SKU 台账
- DeepSeek 生成 9 层提示词
- Seedream 图生图与图片库
- 生成图绑定 SKU、同步 Shopify 媒体
- 类目、价格、库存、Packed size
- 改价审批、驳回、回滚
- 任务日志、飞书通知
- Agent Function Calling
- 本地配置页与一键启动

### 不做

- 自研基础生图模型
- 虚拟试衣、模特生成、视频生成
- 每个品类训练 LoRA
- 高频多账号 SaaS
- 当前阶段接淘宝/京东/拼多多

## 3. 架构

```text
本地浏览器
  ↓
FastAPI（127.0.0.1）
  ├─ 商品中心 / SQLite
  ├─ DeepSeek Prompt Service
  ├─ Seedream Image Service
  ├─ Shopify Admin GraphQL Adapter
  ├─ 审批状态机 + 审计日志
  ├─ Agent Tool Router
  └─ 飞书 Webhook
```

### 分层

| 层 | 文件 | 责任 |
|---|---|---|
| 页面 | `static/` | 总览、商品、生图、审批、Agent、设置 |
| 编排 | `app.py` | API、任务、审批、生成后台任务 |
| 领域 | `ecommerce/prompts.py`、`ai.py`、`shopify.py` | 提示词、生成、平台适配 |
| 数据 | `ecommerce/database.py` | SQLite 迁移、商品/任务/审批/图片 |
| 配置 | `ecommerce/config.py` | 本机 settings.json 与掩码返回 |

## 4. 关键数据表

- `products`：SKU、标题、成本、售价、库存、类目、Packed size、Shopify ID
- `tasks`：动作、SKU、前后值、状态、结果
- `approvals`：审批阈值、幅度、状态
- `price_history`：回滚依据
- `logs`：每一步审计记录
- `generated_images`：SKU、文件、提示词、模板、尺寸
- `image_jobs`：异步生图任务

## 5. 风险控制

1. 改价低于成本价直接拦截。
2. 超过阈值自动进入待审批，不能绕过。
3. 成功改价保存价格快照，可一键回滚。
4. Shopify 同步写入任务与日志，失败保留错误摘要。
5. Agent 只能调用受控工具，不能直接写数据库。
6. API Key 只保存本地 `settings.json`，接口只返回是否配置和长度。

- 本地单机、单用户；未做登录与多租户。
- Shopify Admin API 图片上传使用文件直传；已通过真实店铺验证。

- 国内平台需要新增适配器，不修改核心审批/任务逻辑。
